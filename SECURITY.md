# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | ✅ |
| < 0.2.0 | ❌ |

Security fixes are always released on the latest minor version. Please upgrade to the newest release to receive patches.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue. Instead:

1. Email `stalkermv@ukr.net` with the subject **"CKSwiftData Security"**.
2. Include as much detail as possible:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact and suggested remediation
3. If you need to share sensitive information, request a secure communication channel in your email.

You will receive an initial response within **72 hours**. We will work with you to assess the issue, determine severity, and release a fix. Credit will be given in the release notes unless you prefer to remain anonymous.
